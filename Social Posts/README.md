# Social Posts

Skills and working files for writing and publishing social posts, mostly LinkedIn.

```
Social Posts/
├── .agents/skills/
│   ├── humanizer-zh-en/            English translation of the Humanizer-zh editing skill
│   ├── postiz-post-with-image/     Post or schedule through the Postiz CLI, with an image
│   └── ego-browser-linkedin-post/  Post to LinkedIn by driving the composer in Ego browser
├── .claude/skills/                 Links that let Claude Code find the skills above
└── images/                         Post images (git-ignored, see images/README.md)
```

`.agents` and `.claude` are hidden folders. On macOS, press Cmd+Shift+. in Finder to show them.

The third-party skills these workflows use (`postiz` and `humanizer-zh`) are installed separately; see the [root README](../README.md#quick-start).
